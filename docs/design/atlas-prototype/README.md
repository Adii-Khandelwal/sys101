# Atlas prototype (reference only)

Design-canvas source files (`.dc.html`) of the approved two-ink print redesign, with fake data.
They run only inside the Claude Design canvas (https://claude.ai/artifact/9MvEBCnNshiusWckkWD4DA), not in this app.
Use them to read colours, type, spacing, markup and the small scripts (elbow edge routing, interchange rule, hand-drawn ring, tally marks, registration slide, isometric turntable).
Do not import or ship them. Plan: `docs/redesign-plan.md`.

- Atlas: homepage with theme toggle and review switch. HomeLight and HomeDark: the same page with the theme locked.
- Chapter: topic page with the turntable figure and sidenotes. Phone: the Path view as a vertical line. Compare: navy versus brown dark theme (brown chosen).
